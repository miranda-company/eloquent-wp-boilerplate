== Llummio Editor Helpers ==

Lightweight editor helpers for trusted Llummio blueprint sites.

This plugin adds a Llummio Editor Helpers icon to the block editor toolbar. The icon opens a sidebar with SEO Title and SEO Description fields, robots controls, automatic canonical tags, page-level service-business schema tools, plus an editor-only wireframe toggle for the theme `.wire` helper class. Global business schema is managed from the `Global Schema` admin menu.

See `docs/internal-plugins.md` for maintenance notes and upgrade testing.
