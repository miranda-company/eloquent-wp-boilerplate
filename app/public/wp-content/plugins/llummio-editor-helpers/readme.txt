== Llummio Editor Helpers ==

Lightweight editor helpers for trusted Llummio blueprint sites.

This plugin adds a Llummio Editor Helpers icon to the block editor toolbar. The icon opens a sidebar with SEO Title and SEO Description fields, robots controls, automatic canonical tags, page-level service-business schema tools, per-page GSAP, ScrollTrigger, and SplitText loading toggles, plus editor and frontend wireframe controls for the theme `.wire` helper class. Global business schema is managed from the `Global Schema` admin menu.

See `docs/08-internal-plugins.md` for maintenance notes and upgrade testing.
